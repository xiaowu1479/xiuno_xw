本地采集对接 (v1.1+)

豆瓣信息采集在本地 Python 客户端（tools/xwdi_client）完成后，回传到论坛发布。
后台仅负责：清单导入 → 任务队列 → 接收采集结果 → 发帖；不再直连豆瓣。

>
>
Python 客户端配置（config.json）示例：
{ "site_url": "",
"token": "",
... }
config.json 中填入上述「API 地址」和「API Token」即可对接。
