# 火车头采集器免登录发布接口使用文档

> 对应接口文件：站点根目录 `loco.php`（XIUNO XW 内置）

## 一、简介

`loco.php` 是 XIUNO XW 内置的火车头采集器（Locoy）免登录发布接口。采集完成后，火车头通过 HTTP POST 将标题和内容直接发布为论坛主题，无需登录账号，支持：

- 发布到指定版块
- 关联 xn_tag 插件标签（含"版块+标签"合并栏目列表）
- 以指定用户身份发帖
- 多标签叠加（`tagid` 参数，逗号分隔）

## 二、前置配置

接口密码读取自 `conf/conf.php` 的 `loco_pass` 配置项：

```php
'loco_pass' => '你的密码',	// 火车头采集接口密码，留空则禁用 loco.php
```

**注意：**

- 密码留空或未配置时，接口完全禁用，访问返回 `err:pass_not_configured`
- 请设置足够复杂的密码，任何知道该密码的人都可以向站点发帖

## 三、接口地址一览

以下 `{pass}` 替换为你配置的密码，`http://你的域名` 替换为实际域名。

| 用途 | 地址 |
|---|---|
| 列出版块（JSON，测试用） | `?pass={pass}&action=list_forum` |
| 列出版块（文本，火车头栏目格式） | `?pass={pass}&action=list_forum_text` |
| 列出标签（文本，需 xn_tag 插件） | `?pass={pass}&action=list_tag_text` |
| 合并列出版块+标签（**推荐**，单一栏目列表） | `?pass={pass}&action=list_category_text` |
| 列出用户（JSON），用于确定发帖 uid | `?pass={pass}&action=list_user` |
| 调试：打印收到的全部参数 | `?pass={pass}&action=debug` |
| 调试：查看标签表原始数据 | `?pass={pass}&action=debug_tags` |
| **发布主题（火车头提交地址）** | `?pass={pass}&action=save` |

## 四、火车头采集器配置步骤

### 1. 新建 Web 发布模块

在火车头「发布」中新建在线发布模块，关键配置如下：

| 配置项 | 值 |
|---|---|
| 提交地址 | `http://你的域名/loco.php?pass={pass}&action=save` |
| 提交方式 | POST |
| 编码 | **UTF-8** |

### 2. 配置获取栏目列表

- 栏目列表地址填：`http://你的域名/loco.php?pass={pass}&action=list_category_text`
- 该地址返回 `<<<ID--名称>>>` 格式的列表，火车头可自动解析
- 若不使用标签功能，也可以用 `action=list_forum_text`

### 3. 配置 POST 数据

```
fid=[分类ID]&uid=[标签:用户ID]&subject=[标签:标题]&message=[标签:内容]
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `fid` | 否（默认 1） | 版块 ID；选自栏目列表。若 ≥10000 则被识别为标签 ID（见下文） |
| `uid` | 否（默认 1） | 发帖用户 ID，可通过 `list_user` 查看 |
| `subject` | 是 | 帖子标题 |
| `message` | 是 | 帖子内容 |
| `tagid` | 否 | 叠加标签，多个用英文逗号分隔，如 `tagid=1,2,3` |

### 4. 配置成功/失败标记

| 标记类型 | 内容 |
|---|---|
| 成功标记 | `yes` |
| 失败标记 | `err` |

## 五、合并栏目列表与标签规则（list_category_text）

该接口把版块和标签合并在同一个栏目列表里输出，方便火车头只做一个栏目下拉框：

- **版块**：ID 保持不变（< 10000），如 `<<<1--站务公告>>>`
- **标签**：ID = **10000 + tagid**，名称带 `[标签]` 后缀区分，如 `<<<10005--版块/分类:标签名 [标签]>>>`

服务端处理逻辑（`save` 时）：

1. 收到 `fid >= 10000` 自动识别为标签：换算出真实 tagid（减去 10000），查其所属分类对应的版块作为发帖版块，发帖后自动关联该标签
2. 若同时传了 `&tagid=` 参数，两者叠加（即栏目选的标签 + tagid 参数指定的标签都会关联）

## 六、返回值与错误码

| 返回 | 含义 | 排查方向 |
|---|---|---|
| `yes` | 发布成功 | — |
| `err:conf` | conf/conf.php 加载失败 | 检查配置文件是否损坏 |
| `err:pass_not_configured` | 未配置接口密码 | 在 conf.php 中配置 `loco_pass` |
| `err:db` | 数据库连接失败 | 检查数据库配置/服务状态 |
| `err:pass` | 密码错误 | 核对 URL 中的 pass 参数 |
| `err:empty` | 标题或内容为空 | 检查火车头标签映射是否正确 |
| `err:tagid` / `err:tagcate` / `err:cate_fid0` | 标签/标签分类无效 | 标签可能已被删除或禁用，重新获取栏目列表 |
| `err:fid` | 版块不存在 | 核对 fid，重新获取栏目列表 |
| `err:uid` | 用户不存在 | 核对 uid，通过 list_user 查看 |
| `err:create` | 创建主题失败 | 查看站点 log/ 目录错误日志 |

## 七、常见问题排查

1. **发布失败时**，先把火车头提交地址中的 action 临时改为 `debug`：
   ```
   http://你的域名/loco.php?pass={pass}&action=debug
   ```
   再执行一次发布任务，页面会打印火车头发来的 GET/POST 全部参数，核对 fid、uid、subject、message 是否正确。

2. **中文乱码**：确认火车头发布模块编码选择 UTF-8（站点为 UTF-8 编码）。

3. **栏目列表为空或缺少标签**：标签功能依赖 xn_tag 增强版插件；可用 `action=debug_tags` 直接查看标签表数据。

4. **安全建议**：定期更换 `loco_pass`；如不需要采集功能，将 `loco_pass` 留空即可禁用接口。
